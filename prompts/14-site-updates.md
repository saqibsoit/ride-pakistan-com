# Prompt 14: Site updates (WhatsApp button, contact details, customers list, email notices)

Read `CLAUDE.md`, `docs/PLAN.md` and `docs/reference/DESIGN-REFERENCES.md`. Start in plan mode and wait for approval. Work on a feature branch; run all checks, push and open a PR when done.

1. **WhatsApp button.** Floating button, bottom-right, on every public page (not admin). Opens `https://wa.me/923344554500` with a pre-filled message ("Hi Ride Pakistan, I'd like to ask about riding sessions."). Number and message come from Settings. Brand styling, accessible label ("Chat with us on WhatsApp"), keyboard focusable, respects safe-area insets. On pages with the mobile booking bar it sits above the bar, never overlapping. No third-party script (plain link), CSP unchanged. Track a `Contact` click event only when analytics consent is given.
2. **Email and WhatsApp number at booking.** Both required in the booking flow (guest and signed-in). WhatsApp number validated (E.164, Pakistani and international numbers), with "this is also my WhatsApp" pre-filled from the profile phone. Save to the customer's profile; show on the run sheet, order page and exports. Existing customers without one are asked on their next booking.
3. **Customers list (admin).** Extend the Customers screen: sign-up date, email, WhatsApp number, number of bookings, total paid (PKR), last booking date, lead source. Filters (sign-up date range, has booked / never booked, source) and CSV/Excel export (admin only, audit-logged, rate limited).
4. **"Check your spam folder" on every email notice.** Everywhere the site tells a user an email was sent (login code screen, booking confirmation page, transfer received, gift voucher sent, waitlist offer, contact form, password/MFA screens for team), add: "Can't see it? Check your spam or promotions folder." Also add one line near the top of every outgoing email asking recipients to mark the sender as safe if it landed in spam. One shared component, tested.
5. **Helmet notice.** Riders bring their own riding helmet. Update the FAQ ("What should I wear?"), the "What to bring" list on product pages, the booking confirmation email and the 24-hour reminder: "Please bring your own riding helmet. Riders without a helmet can't ride."
6. **Private session blocks the slot.** Confirm with tests that once a private session is held or booked on a slot, no single, group, package-credit, waitlist or admin booking can be added to it, and that a private session can't be booked on a slot that already has any booking or hold. Fix any path that allows it.
7. **Photo band fix (if not already merged).** The two-image band between "2 hours, start to finish" and "Meet Omar Saleem" must render side by side at equal height on desktop and as one image on mobile, with a browser test.

Acceptance: tests for each item, a browser test for the WhatsApp button (position, no overlap with the booking bar on mobile) and the spam notice on the login code screen.
